# 界面与稳定性检查（2026-09-08）

本页记录 preview.2 的界面验收。官网现已更新为含 P2P 的 preview.3，桌面网络层同步升级，但继续使用已发布的窗口实现；下文无边框窗口实验仍未发布。当前下载校验值见 [发布状态](RELEASE_STATUS.md)。

## 已发布：Android 2.0.0-preview.2

- 连接、审批、错误、发送文字和远程工具统一紧凑圆角弹窗；长内容内部滚动、输入键盘避让，错误不重复堆叠。会话结束关闭会话弹窗，Activity 销毁清理其窗口；设置弹窗随仪表盘移除关闭。真正的系统共享和权限授权窗口不替换。
- 仪表盘设备码按三位分组、PIN 隐藏/显示、更换和一次复制两个值；缩小装饰性间距，保留可点击区域。蓝色自适应图标背景填满系统蒙版，不使用白色图标底。
- 控制电脑默认相对鼠标，移动合并但不丢按下/抬起；发送点击前明确发送坐标。左右键、一次手势拖动、双指滚动、旋转/取消/失焦释放；没有授权或会话未就绪时不发送输入。
- Windows 后退为 Alt+左方向键、桌面为 Win+D；Android 返回/主页由远端已授权的无障碍服务执行。其他系统明确使用 Esc/Home 键名称，不误报为系统桌面。旋转保留会话。

验证：Go 核心 `-race -count=3`、vet；19 项 Java 测试；四 ABI gomobile/Gradle 构建；lint 0 错误、1 个本地空资源目录提示；签名验证及 16KB ZIP 对齐。最终源码与构建副本逐项比对。版本代码 2000002，包名 `cn.yucg.yudesk.preview`，签名与上一官网预览版一致，可覆盖安装。

官网完整下载 25,522,471 字节，SHA-256：

`f37c7dd04efc412354cfe9b53ce177511762f0425726dacca6c047818de2223f`

Android 仍未连接真机：本记录不证明手机上的视觉效果、GPU、手势、厂商后台、弱网或长时间稳定性全部合格。声音、文件和剪贴板同步尚未提供。不得以自动化通过宣称零延迟、所有手机兼容或达到 ToDesk 的性能。

## 未发布：Windows 原生无边框窗口

仅修改 Chromium 的 WS_CAPTION 不能去掉其客户端区域内自绘标题栏。实验实现用 Go 自有窗口承载网页、按实际 renderer 边界布局，而非固定像素裁剪；隐藏复用同一宿主与浏览器 PID。

已通过隔离 Chrome/Edge 窗口几何、导航、尺寸变更、最大化/恢复、标题属性修复及连续十次隐藏/恢复。未注入真实鼠标/键盘，未锁定真实桌面。

**发布阻断：**退出后浏览器进程句柄在等待上限内未 signaled，部分缓存文件仍占用。无窗口嵌入的独立 Chromium Job 测试同样失败，而普通 `cmd /c exit 0` 对照通过。Job 的 ActiveProcesses=0 或强制终止指定的退出码 0 都不足以证明系统清理已完成。

恢复原浏览器样式、解除父子关系/输入队列、专用 GUI 线程退出、隔离标准句柄均未消除对照失败。目前不能确认具体驱动、挂起 I/O 或浏览器内部原因，不将其武断归因于杀毒软件。

本地补充终止后的有界等待及真实错误返回，保留失败测试，不将超时改成成功。下一步需定位具体待完成资源，并在 Chrome、Edge、隐藏恢复与真正退出路径都通过后再构建和替换 Windows 下载。实验文件未纳入本次 main 提交，官网 Windows 二进制及其他桌面包保持原样。

本轮 Android 发布仅替换 APK；中转 PID、配置、数据库、许可和桌面发布元数据保持不变。旧 APK 与元数据可从服务器 `backups/android-v2.0.0-preview.2` 恢复。
