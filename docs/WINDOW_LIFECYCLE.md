# 紧凑窗口与关闭行为

> 2026-09-09：三个桌面平台的普通窗口固定为 860×600 逻辑像素，无系统标题栏和四边黑框，仍可移动、最小化并主动整屏显示。Windows 本机原生窗口、Linux 隔离图形回归及 Mac 双架构 SDK/安装包检查通过；不代表所有平台真机远控验收。最终版本与校验见 `RELEASE_STATUS.md`，本轮验证见 `FIXED_WINDOW_20260909.md`。

2.0.0 按用户最新要求，主界面提供隐藏、最小化和关闭；远程会话只保留最小化与“结束控制”：

| 操作 | 行为 |
| --- | --- |
| 主界面的 X / 关闭 / 退出 | 结束会话及 YuDesk 主应用，不再弹出退出结果页或重开主界面 |
| 远程会话“结束控制” | 显示紧凑确认框，确认后在原窗口返回主界面 |
| 远程会话工具栏 | 默认收起设置面板；不显示“隐藏”和“×”，保留最小化 |
| 最小化 | 保留任务栏及 Windows 托盘图标，连接不中断 |
| 隐藏 | 界面、任务栏及 Windows 托盘图标消失，主进程继续运行 |
| 隐藏后再次双击 / Windows Ctrl+Y+U | 复用主进程恢复界面及图标 |
| Windows 托盘双击 / 右键 | 显示窗口 / 显示或退出应用 |

主界面按钮顺序：隐藏 → 最小化 → 关闭。远程会话不提供隐藏和关闭按钮，避免误杀主程序。Windows 移除 Chromium 应用窗口的系统标题栏；macOS 使用 AppKit/WKWebView、Linux 使用 GTK/WebKitGTK 无装饰窗口，均保留内部操作区。Unix 官网下载提供完整原生安装包，Mac 尚未公证。macOS/Linux 尚未实现系统托盘与全局快捷键。Ctrl+Y+U 仅在 Windows 隐藏时检测这三个按键的同时按下状态，不记录或拦截键盘输入；前台其他应用仍可能响应自身的 Ctrl+Y 快捷键。

只输入设备码时，被控端显示自定义确认框，最长 60 秒，默认拒绝；隐藏中的应用自动显示该请求。明确同意才允许本次指定的控制/观看模式。错误 PIN 不自动降级确认；请求者取消、超时、停止接入或应用退出后，旧请求不能再批准。每分钟最多三次确认请求，不提供永久免密许可。

Windows 官网 EXE 是独立一体化安装器。点击“立即安装”后请求一次系统管理员授权，后台写入正式程序和服务，创建桌面、开始菜单快捷方式并直接打开安装版；不会先打开便携版，也没有旧窗口退出后再启动新窗口的闪跳。设置仍可检查、修复或卸载桌面服务。

已安装的 `YuDeskDesktop` Windows 系统服务独立运行；退出主界面不会卸载系统服务，远控也不会因此在后台继续连接。需停止该能力时使用设置中的“卸载桌面服务”。管理员授权对话框由 Windows 提供，应用不能替换其外观。

## 窗口与界面

- 普通窗口固定为 **860×600 逻辑像素**（高 DPI 下按系统缩放），禁止拖边缩放和最大化；远程桌面仍可手动整屏显示，退出全屏恢复固定尺寸。
- 设备码字段约 194px，PIN 约 108px，连接按钮约 76px，随窄屏适当压缩。
- 设备授权状态与授权码输入都放在“设置”页，不占主界面空间；授权码仍默认折叠。
- 固定应用外壳，页面不横向/纵向滚动；设备列表分页；远程侧栏分为画面、网络、剪贴板、文件四栏，文件列表每页 3 项。
- 蓝色 Yu 标记用于界面及 favicon；Windows 可执行文件内嵌 ICO。Unix 打包脚本生成 macOS .icns，Linux 安装桌面菜单与 scalable 图标，不把网页 favicon 等同于系统应用图标。
- 结束确认、连接/返回过程采用相同浅色紧凑样式，不再使用浏览器原生 confirm 或整页深色大标题。

## 独立界面进程

Windows 使用安装在电脑上的 Microsoft Edge、Google Chrome 或 Chromium 显示界面。系统服务和 Go 主程序不需要浏览器管理员权限。不使用无法可靠关闭/隐藏的普通浏览器标签页作为降级窗口。macOS/Linux 安装包使用自有原生窗口组件，不再依赖 Chromium 应用窗口；需系统 WebKit / 安装包声明的 WebKitGTK 依赖。

每个本机应用地址和访问令牌对应专用浏览器 profile，与用户日常浏览器隔离。窗口管理通过 Chromium 的本机调试接口执行，只监听回环地址、随机端口，保留默认 Origin 检查；没有向公网开放调试端口，也没有使用全局浏览器进程名结束其他窗口。不可使用 `--remote-allow-origins=*` 或把该本机端口转发到外网。

托管窗口直接订阅自己的 target 销毁事件，避免 Chromium 未消费的 HTTP 长连接滞留导致 X 检测延迟。Windows 隐藏现有原生宿主时仍保留销毁监听，避免渲染器崩溃后留下失去界面的主应用；退出时才撤销监听并清理进程。HTTP 页面存活检测继续用于非托管/测试页面，不与原生窗口重复触发退出。

Windows 使用自有无标题栏、固定尺寸的原生窗口承载网页内容。仅去掉 WS_CAPTION 不足以去掉 Chromium 自绘标题栏；宿主按真实 renderer HWND 边界布局，客户区与外部窗口四边完全重合，不使用裁剪黑边或强制全屏。隐藏使用 SW_HIDE，恢复复用同一窗口和专用浏览器 PID；退出才清理窗口、消息线程及专用进程组。macOS/Linux 使用固定普通窗口并保留显式全屏切换；Go 与窗口组件通过匿名管道通信，令牌不进入命令行参数。只有明确关闭事件才视为用户退出；Unix 窗口组件异常停止后再次打开可重建，不因此终止 Go 主应用。设备身份、授权、连接列表等持久数据不变。

## 验证边界

原生生命周期测试使用隔离 Chromium，不操作远程设备；验证重复打开、主界面关闭、隐藏后在线和恢复，显式“结束控制”另行验证返回主界面。窗口几何测试短暂显示隔离测试窗口，验证无系统标题栏、四边零边框、拒绝缩放/最大化以及最小化恢复。

Windows 通过专属 Job Object 管理新启动的 YuDesk 浏览器进程组。进程以挂起方式创建，加入作业后通过实际主线程句柄恢复，避免子进程提前逃出清理范围；退出时先请求正常关闭，再回收仍存活的专属子进程。不按浏览器进程名称批量结束其他窗口，关闭等待有上限且保留错误反馈。

浏览器截图及自动化覆盖 860×562 内容区、窄屏、设备分页、确认框、设置/剪贴板/文件面板。macOS/Linux 编译验证不等于各自窗口管理器的真机验收。
