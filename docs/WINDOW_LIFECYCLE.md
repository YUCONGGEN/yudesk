# 紧凑窗口与关闭行为

2.0.0 按用户最新要求，所有 X 都关闭应用，仅“结束控制”返回主界面：

| 操作 | 行为 |
| --- | --- |
| 任意界面的 X / 关闭 / 退出 | 结束会话及 YuDesk 主应用，不再弹出退出结果页或重开主界面 |
| 远程会话“结束控制” | 显示紧凑确认框，确认后在原窗口返回主界面 |
| 最小化 | 保留任务栏及 Windows 托盘图标，连接不中断 |
| 隐藏 | 界面、任务栏及 Windows 托盘图标消失，主进程继续运行 |
| 隐藏后再次双击 / Windows Ctrl+Y+U | 复用主进程恢复界面及图标 |
| Windows 托盘双击 / 右键 | 显示窗口 / 显示或退出应用 |

按钮顺序：隐藏 → 最小化 → 关闭。Windows 移除 Chromium 应用窗口的系统标题栏，保留内部操作区及拖动；macOS/Linux 保留各自原生标题栏，尚未实现各自系统托盘与全局快捷键。Ctrl+Y+U 仅隐藏时检测这三个按键的同时按下状态，不记录或拦截键盘输入；前台其他应用仍可能响应自身的 Ctrl+Y 快捷键。

只输入设备码时，被控端显示自定义确认框，最长 60 秒，默认拒绝；隐藏中的应用自动显示该请求。明确同意才允许本次指定的控制/观看模式。错误 PIN 不自动降级确认；请求者取消、超时、停止接入或应用退出后，旧请求不能再批准。每分钟最多三次确认请求，不提供永久免密许可。

已安装的可选 `YuDeskDesktop` Windows 系统服务仍独立运行；退出主界面不会卸载系统服务，远控也不会因此在后台继续连接。需停止该可选能力时使用设置中的“卸载锁屏服务”。

## 窗口与界面

- 默认外部窗口约 **860×600**（高 DPI 下按系统缩放），不再默认全屏；远程桌面仍可手动整屏显示。
- 设备码字段约 194px，PIN 约 108px，连接按钮约 76px，随窄屏适当压缩。
- 设备授权状态与授权码输入都放在“设置”页，不占主界面空间；授权码仍默认折叠。
- 固定应用外壳，页面不横向/纵向滚动；设备列表分页；远程侧栏分为画面、网络、剪贴板、文件四栏，文件列表每页 3 项。
- 蓝色 Yu 标记用于界面及 favicon；Windows 可执行文件内嵌 16/24/32/48/64/128/256 像素 ICO 资源。macOS/Linux 的独立原生安装包图标尚未制作，不把网页图标等同于 Finder/启动器图标。
- 结束确认、连接/返回过程采用相同浅色紧凑样式，不再使用浏览器原生 confirm 或整页深色大标题。

## 独立界面进程

YuDesk 使用安装在电脑上的 Microsoft Edge、Google Chrome 或 Chromium 显示界面。系统服务和 Go 主程序不需要浏览器管理员权限。现在需要其中一种受支持的浏览器；不再用无法可靠关闭/隐藏的普通浏览器标签页作为降级窗口。

每个本机应用地址和访问令牌对应专用浏览器 profile，与用户日常浏览器隔离。窗口管理通过 Chromium 的本机调试接口执行，只监听回环地址、随机端口，保留默认 Origin 检查；没有向公网开放调试端口，也没有使用全局浏览器进程名结束其他窗口。不可使用 `--remote-allow-origins=*` 或把该本机端口转发到外网。

托管窗口直接订阅自己的 target 销毁事件，避免 Chromium 未消费的 HTTP 长连接滞留导致 X 检测延迟；主动隐藏先撤销关闭监听。HTTP 页面存活检测继续用于非托管/测试页面，不与原生窗口重复触发退出。

隐藏时关闭专用渲染器，重开时由同一 Go 主程序恢复界面。设备身份、授权、连接列表等持久数据不变；尚未提交的输入草稿（包括 PIN）不会为了隐藏而持久保存。网络传输、截图和输入处理均不依赖页面是否显示。

## 验证边界

原生生命周期测试使用隔离 Chromium，不操作用户真实鼠标键盘；通过关闭真实浏览器 target 触发与 X 相同的关闭事件，验证重复打开、真正关闭界面、隐藏后在线和恢复。会话 X 验证退出本机主应用、对端仍存活；显式“结束控制”另行验证返回主界面。窗口几何测试会短暂显示隔离测试窗口，验证移除系统标题栏以及最小化恢复。

Windows 通过专属 Job Object 管理新启动的 YuDesk 浏览器进程组。隐藏或退出时先请求正常关闭，再回收仍存活的专属后台子进程，避免缓存文件被遗留占用；不按浏览器进程名称批量结束其他窗口。Chrome 和 Edge 均有原生回归测试。

浏览器截图及自动化覆盖 860×562 内容区、窄屏、设备分页、确认框、设置/剪贴板/文件面板。macOS/Linux 编译验证不等于各自窗口管理器的真机验收。
