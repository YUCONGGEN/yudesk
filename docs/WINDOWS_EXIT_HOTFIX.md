# Windows 自动退出修复（2026-09-09）

## 修复范围

- 远程流 EOF、连接重置或读包错误只结束当前会话；主程序保留并返回连接首页，显示断线提示。
- 窗口监控 WebSocket 出错时以 100ms 至 2s 的退避间隔恢复连接，并核验本应用窗口。监控出错本身不触发程序退出。
- 真正的窗口关闭事件、两次成功查询确认窗口消失，或确认本应用浏览器进程已结束且恢复失败，仍遵循关闭窗口即退出的行为。
- 隐藏、再次打开、退出会取消旧监控；旧监控不会关闭替代窗口。
- 手动退出、X、托盘退出及原有管理员终止设备逻辑保留，不自动绕过授权或后台下线。

## 诊断日志

Windows 默认位置：`%APPDATA%\yudesk\logs\lifecycle.log`。
当前日志及上一份 `.1` 各最多 256 KiB。只记录时间（带时区）、进程号、固定事件名和错误类别；不捕获普通控制台日志，不记录设备 PIN、令牌、剪贴板、画面及远端错误正文。
日志目录不可写不会阻止软件启动。正常退出会记录 `app_stopped`；强制结束进程或运行时崩溃未必能写最后一条，这不是完整崩溃转储系统。
