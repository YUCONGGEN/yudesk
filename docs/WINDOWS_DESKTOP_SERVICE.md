# Windows 桌面服务与锁屏恢复

## 用户操作

1. 两端都从官网下载新版 Windows 安装器，双击后点击“立即安装”，完成一次 Windows 管理员授权。
2. 安装器默认写入 `C:\Program Files\YuDesk\yudesk.exe`，也可在折叠的“自定义安装目录”中选择本机空目录；随后启用锁屏服务、登记到 Windows“程序和功能”并创建桌面和开始菜单快捷方式。完成后直接打开正式程序，不需要手动切换或重启。
3. 以后从桌面、开始菜单或安装目录打开 YuDesk。设置页仍提供“修复 / 更新安装版”和卸载服务入口。
4. 安装和切换沿用同一用户的设备身份、授权和连接记录。主界面需要保持运行或隐藏在线；关闭主界面后系统服务不会独立接收远控。
5. 不再需要时点击“卸载锁屏服务”并确认管理员授权。卸载只删除此服务注册并结束它的辅助进程，保留安装文件及设备配置，便携模式仍可用。

## 边界

- 服务名 `YuDeskDesktop`，LocalSystem，自动启动；只监督本机活动控制台会话的一个桌面辅助进程。可选服务模式为主程序＋服务＋辅助进程，便携模式仍只有一个常驻主程序。
- 仅本机命名管道通信，无 TCP/HTTP 监听。服务不连接中转，不保存 Windows 密码，不读取浏览器或登录凭据，不支持运行任意命令或任意文件操作。
- 默认路径由 Windows Program Files 已知文件夹解析；自定义路径保存在管理员可写的 HKLM 安装登记中，服务和桌面进程共同验证该位置。目录所有者为 Administrators；SYSTEM/管理员可写，普通用户只读执行；拒绝网络、磁盘根、链接及含无关文件的自定义目录。
- 管道拒绝网络身份，仅交互会话可接入；双方用管道 PID、会话及受保护的可执行文件路径校验；客户端额外验证管道所有者为 SYSTEM。
- 工作进程向交互用户仅授予进程路径查询权限，不授予写内存、获取令牌、终止或创建线程权限。管道只接受采集和输入，两类操作各有独立并发上限和超时。
- 采集/输入在专属锁定 OS 线程上临时绑定当前输入桌面，结束后恢复。不会主动切换用户可见桌面，也不会解除系统锁定。恢复失败时辅助进程关闭，由服务受控重启。
- 辅助进程挂入 Kill-on-close Job。服务停止会结束它的进程，意外退出有退避重启，不会不断积累子进程。
- 高权限画面管道最大宽度 3840，并有 32 MiB 原始帧面积上限；超限按比例缩小，仍保留源坐标尺寸供输入映射。

## 已知限制

- 仅 Windows 10/11 x64 本机活动控制台会话；Windows RDP、多用户并发会话未支持。
- 不实现 Ctrl+Alt+Del 安全注意序列，不修改 Windows 登录策略，也不绕过系统密码；要求安全注意序列的登录页不属于当前完整支持范围。
- 主程序退出或用户注销后不会自动以用户身份重启主界面。此服务不是完整的开机无人值守远控产品。
- 锁屏/系统授权期间剪贴板暂停；中文剪贴板在普通用户桌面使用原生 CF_UNICODETEXT，不通过系统代码页转码。
- 普通模式采集失败不会终止会话：每秒重试一次，通知 Viewer 暂不可用，恢复时发送完整关键帧；等待期间阻止新鼠标、滚轮、键盘及 IME 输入。
- Windows 本机正常桌面已做服务链路实测。遵守本次测试授权，**没有主动锁屏、输入系统密码或注入真实鼠标键盘**，因此 Winlogon 登录页实际控制、解锁连续性和 UAC 安全桌面仍待真机验收，不可描述为全部验收通过。

## 本轮验证

- 当前开发电脑显式授权后安装服务；安装版真实采集 1920×1080 源桌面，并返回 640×360 RGBA，921,600 字节。
- 当前内置管理员账户没有 UAC linked token；使用去掉管理员权限及特权的中等完整性受限令牌运行安装版采集诊断，成功。未新建或修改系统账户。
- 非安装路径调用被拒绝；服务不接受命令、文件、令牌或剪贴板方法。
- 独立 window station 的原生剪贴板测试覆盖中文、繁体、日韩文字、emoji、扩展字符、多行、空文本及尾部空白，拒绝内嵌 NUL。没有读取/覆盖用户实际剪贴板。
- JPEG 与 tiles 两种模式覆盖“连接时已锁定”和“连接后桌面失效”，恢复后继续原连接并强制完整帧；取消重试立即结束。
- 浏览器测试覆盖应用中/成功/失败可见反馈、模拟中文剪贴板 HTTP 往返、桌面不可用遮罩、等待期间滚轮及 IME 阻断、恢复，无真实 OS 输入。
- 原有 Windows 原生体验、文件上传/下载 98,321 字节校验、10 项旧客户端及 5 项合并客户端生命周期、设备列表与返回主页回归通过。

## 开发验证入口（普通用户不需要命令行）

`yudesk.exe -desktop-service-check` 仅输出服务状态、截图尺寸和字节数，不输出画面或发送输入。必须从受保护的安装路径运行。命名管道测试需设置 `YUDESK_TEST_INSTALLED_SERVICE=1`，只应在用户明确授权安装后使用。

参考 Microsoft 文档：[OpenInputDesktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-openinputdesktop)、[SetThreadDesktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setthreaddesktop)、[GetNamedPipeServerSessionId](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getnamedpipeserversessionid)、[SetClipboardData](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setclipboarddata)。
