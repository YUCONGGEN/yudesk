# YuDesk Android 2.0.0-preview.2

Android 双向端采用原生 Java 界面和 Go 通信核心，一个应用可控制另一台设备，也可在本机明确授权后被控制。iOS 开发已暂停。

## 交付状态与适用范围

这是**预览版，不是已经完成所有手机兼容验收的正式版**。最低 Android 8.0 / API 26；构建包含 `arm64-v8a`、`armeabi-v7a`、`x86_64`、`x86`。制造商后台策略、安全桌面、系统应用和受保护视频可能限制共享或触控。不承诺“所有安卓手机都行”，不支持绕过系统锁屏、DRM 或 `FLAG_SECURE`。

本地 Go 竞态测试、协议合成联调及 Java SDK 35 编译检查不能代替真机测试。当前没有连接的 USB 测试手机；屏幕共享、实际拖动、旋转、锁屏、后台限制及设备间公网性能仍需真机验收。工作流产物必须通过构建、单元测试、lint、签名检查和 16KB ZIP 对齐检查之后才提供下载。

上一版 `preview.1` 的本地完整构建验证已通过：Go 核心 `-race -count=3`、`go vet`、四架构 gomobile 绑定、6 项 Java 单元测试、Android lint（零问题）、APK 打包、`apksigner verify` 和 `zipalign -c -P 16`。该构建包含 Bitmap 生命周期、连续移动事件合并和连接关闭不阻塞 UI 的修复。该结果仅代表自动化构建与测试通过，不代表真机或厂商兼容性验收完成；APK 是调试签名预览版。

`preview.2` 在前述构建基础上新增鼠标/触屏模式、主动横竖屏切换、按远端平台区分导航、紧凑界面、满底蓝色自适应图标以及统一的自定义弹窗。19 项 Java 测试覆盖点击前定位、左右键、拖动释放、滚动方向、分辨率变化、旋转缩放、10,000 次移动合并和平台快捷键；Go 竞态三轮及签名/16KB 对齐检查通过。APK 的版本号为 `2000002`，沿用上一版本地签名，可覆盖安装，设备身份不变。最终本地 lint 为 0 错误、1 条空资源目录提示（不进入 Git/APK）；未做真机视觉、手势及长期负载验收。

应用内连接等待、审批、错误、工具与文本提示采用统一圆角样式；长内容在弹窗内滚动、文字输入支持键盘避让，重复错误不会层层堆积；退出会话关闭该会话的工具/文本弹窗，销毁 Activity 会清理其弹窗。屏幕共享与权限授权始终使用真实 Android 系统窗口，不替换或伪装。复制反馈显示在界面中，不弹出自定义伪系统提示。

## 使用

1. 安装带有 **Android 预览版**标记的 APK。首次开启应用会显示设备码（9 位数字）和 PIN（6 位数字）。网络管理通道验证成功且管理员授权后可以连接；设备未激活时，联系网站管理员在后台激活，不会把 HTTP 网页的返回值当作可信许可证。
2. **作为被控端**：点击“授权共享屏幕”，先允许通知，再通过 Android 自带的屏幕共享授权。每次开启共享都要重新授权，不能自动记住或重放系统授权。持续通知中的“停止共享”随时有效。
3. 需要远程操作时，点击“开启远程触控权限”，阅读用途后自行进入系统设置启用 YuDesk 无障碍服务。只观看无需此权限；若连接后才打开触控权限，请重新连接。Android 13+ 安装来源触发“受限设置”时，由手机持有人按系统说明处理；软件不会绕过。
4. **作为控制端**：输入另一台设备的设备码；PIN 可以留空，也可以填入正确的 6 位 PIN。勾选“仅观看”时不发送操作。
5. 留空 PIN 时，被控手机显示 YuDesk 自定义的允许/拒绝对话框，后台时由通知引导用户返回应用处理。最多等待 60 秒，超时拒绝；每台设备同一时间只接受一个审批，每分钟最多三次。错误 PIN 不会降级为审批。
6. 连接电脑默认使用**鼠标模式**：单指滑动移动蓝边白色箭头、轻点左击、连续轻点双击、双指上下滑动滚动。底部提供左键、右键、拖动和文字；“拖动”开启后下一次单指滑动按住左键，抬手即释放。可切换“触屏”直接点选画面位置。横屏按钮可主动切换方向，无需开启手机自动旋转；旋转不会重新建立连接，旋转或切后台会释放远端按键。
7. 工具菜单中的按键按远端系统区分：Windows“后退”发送 Alt+左方向键（适用于资源管理器、浏览器等支持该快捷键的窗口），“桌面”发送 Win+D；Android“返回 / 主页”使用对端已授权的无障碍系统操作。其他系统明确标为 Esc / Home 键，不把普通 Home 键冒充桌面。手机自身的返回键只结束当前连接、回到 YuDesk，不发送给远端。中文文字通过 UTF-8 协议和 Java Unicode 传递，不借用系统剪贴板。
8. “结束”返回主界面，释放远程输入；主界面“退出”停止接收、停止屏幕共享并关闭应用界面。锁屏、系统撤销共享或划掉应用任务会停止共享，需要重新授权。

设备历史只保存最近 12 个设备码，**不保存 PIN**。列表点击填入后，在发起连接时检测可连接性；本预览版不会把历史记录伪装成实时在线状态。复制功能一次复制本机设备码和 PIN，更换 PIN 后通过证书固定校验的 TLS 管理通道同步给服务器。

## 传输与安全边界

- 默认中转 `www.yucg.cn:8233`，TLS 1.3，固定服务端证书 SHA256：`20FC953E48B6BEED7FB3A5F73BF177CC4E2557CF274C409FF4F0179E5FA0F836`。
- 会话在 Relay TLS 之上复用 X25519 / Ed25519 / HKDF / AES-GCM 端到端加密。设备身份必须与解析的 9 位设备码匹配；PIN 认证在端到端通道内进行。
- 按既有管理需求，管理服务器可以通过已验证 TLS 通道读取设备 PIN；这不应被描述为“服务器完全无法获知 PIN”。应用只信任经证书验证并完成设备签名挑战的管理授权。
- 管理通道中断会撤销接收和控制权限，恢复验证后才重新接收；授权到期即使离线也停止。明确拒绝、禁用、删除、断开不会无限自动重连，界面显示停止原因。
- 私钥和 PIN 只写入 Android 应用私有目录，关闭 Android 备份。无开机启动、隐藏捕获、覆盖安装或系统权限绕过。无障碍服务即使仍由系统保持启用，也必须在每次事件执行时重新验证会话、共享和权限状态。
- 网站仍是用户要求的 HTTP `http://www.yucg.cn:8235`；应用自身关闭明文网络连接，不经 HTTP 发送 PIN、认证或许可证请求。HTTP 下载本身不提供传输完整性，安装前可与受信渠道提供的 SHA256 比对。

## 低延迟设计

采集/压缩、网络写入、网络读取、原生触控、原生解码分别有独立的有界执行通道。采集使用 `acquireLatestImage`，最多保留一个待发完整画面；发送窗口最多两帧，慢网络不积压陈旧画面。原生渲染工作线程在 UI 消费前不继续堆积 Bitmap；输入与采集不共用一个耗时线程。连续输入失败、拥塞和权限拒绝会报告给控制端。

已交给 View 的 Bitmap 在换帧、窗口关闭时均不手工 `recycle()`，因为硬件加速 RenderThread 可能仍引用旧 display list。应用只持有一个已提交帧引用，系统和 GC 在渲染引用释放后回收像素；仅未提交的废弃解码帧主动回收。`FrameSlotTest` 覆盖 10,000 次换帧和关闭期间待提交帧处置，不把这项单测等同于真实 GPU/手机压力验收。

无障碍输入队列会合并连续待执行的移动事件，保留最新坐标，不跨越按下/抬起/键盘事件边界。`InputQueueTest` 验证 10,000 次移动仍保持有界，关键事件保持顺序；如果关键事件队列也拥塞，则释放本会话输入并明确报告错误。

预览阶段使用最长边 1280、JPEG 75、目标最高 30 FPS；桌面被控时协商 JPEG 完整帧、默认 8 Mbps 负载预算。完整帧可安全替换旧帧；不使用“丢弃不同区域的差分块”这种会损坏画面的队列策略。实际帧率受屏幕变化、CPU、JPEG 编码和往返延迟影响，**不保证固定 30 帧，更不能保证零延迟**。

## 构建

目录独立：`mobile/go.mod` 使用 `replace github.com/yudesk/yudesk => ..`，不改根模块依赖。Android 只导入 Go 协议模块，不依赖桌面截图、Windows 服务、浏览器或 SQLite。

要求：Go 1.27.1、JDK 17（本地编译检查亦可用 JDK 21）、Android SDK 平台 35、Build Tools 35.0.0、NDK 27.3.13750724、curl、unzip。

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.3.13750724"
bash mobile/scripts/build-android.sh
```

脚本固定 gomobile/gobind `v0.0.0-20260821190718-4776eadac327`、AGP 8.10.1、Gradle 8.11.1；Gradle 下载有固定 SHA256 校验。产物：`mobile/build/YuDesk-2.0.0-android-preview.apk` 及 `mobile/build/SHA256SUMS.txt`。

GitHub Actions：`.github/workflows/android.yml`，仅申请仓库读取权限，支持手动运行和相关路径推送触发，不自动发布 Release 或上传服务器。生成的是**调试签名预览 APK**，不是正式商店发布包。不同运行器生成的调试密钥可能不同，不保证覆盖安装旧预览；不得以自动卸载旧版来规避签名冲突（卸载会丢失设备身份和设置）。正式发布需要单独管理并备份签名密钥，目前没有提交任何签名私钥。

## 真机验收清单

- Android 8/10/13/14/15/16，不同厂商至少两台物理手机；额外验证 16KB 页面设备。
- 手机控制 PC、PC 控制手机、两台手机互控；分别测试 PIN、无 PIN 同意、拒绝、60 秒超时、等待中取消、错误 PIN 和频率限制。
- 共享授权取消、通知拒绝、触控权限撤销、旋转/分辨率改变、本机触控打断手势、锁屏/解锁、切到后台、划掉任务、停止通知。
- 管理禁用、断开、删除、过期、离线期间过期；无陈旧会话继续操作，无紧密循环重连。
- 长时间（至少 30 分钟）滚动、视频和文字变化，记录 FPS、RTT、触控到画面延迟、内存、温升和耗电；通过才宣称对应设备验收完成。
