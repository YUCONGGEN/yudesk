# YuDesk 2.0.0 安装生命周期与会议姓名更新（2026-09-13）

部署批次：`desktop-lifecycle-20260913.10`

## 用户可见变化

- Windows 安装版现在出现在“设置 → 应用 → 已安装的应用”和传统控制面板“程序和功能”中，可从系统入口完整卸载。
- 安装器默认安装到 `Program Files\YuDesk`，展开“自定义安装目录”后可选择安全的本地绝对目录；安装仍只需要一次系统管理员授权。
- Windows 主界面点击 X 会关闭到托盘并保持在线；需要彻底结束时使用托盘菜单“退出”。重复双击桌面图标只恢复已有窗口，不再叠加两个主界面。
- 桌面和 Android 的会议姓名默认保持空白。姓名不再跨启动保存，发起会议与加入会议的输入也不会互相覆盖；每次参会由用户主动填写。
- Android 升级为 `2.0.0-preview.16 / 2000016`；远控、横屏全屏、会议、声流和授权共享能力保持不变。

## 安全与稳定性

- 自定义安装目录拒绝相对路径、UNC/网络位置、磁盘根目录、链接及包含无关文件的现有目录；系统服务只信任管理员登记的精确程序路径。
- 卸载不递归删除自定义目录，不删除用户设备身份、连接记录或浏览器数据；如果程序正在使用，仅安排删除精确登记的可执行文件。
- 原生窗口关闭、最小化、显示与重复唤醒统一串行处理，短时间重复请求会合并，避免并发创建或显示两个窗口。
- 正式部署脚本在停服前连续检查两次参与连接和活动会话，发现正在使用时立即取消发布；失败路径仍恢复旧程序、配置及下载文件，数据库不被发布包覆盖。

## 构建与发布验证

- 全量 Go 测试和静态检查通过，Windows 安装器载荷验证以及本机安装、程序列表、系统服务、X 到托盘和单 GUI 检查通过。
- Android 四 ABI 核心竞态测试、Java 单测、lint、APK v2 签名和 16 KiB 对齐通过。
