# YuDesk 2.0.0 会议扩容与全屏共享更新（2026-09-13）

部署批次：`meeting-scale-share-20260913.12`

## 本批用户可见变化

- 会议不再设置 8 人应用层硬上限；成员列表和视频网格可继续容纳更多参会者。WebRTC 网状会议的实际容量仍受终端性能和上行带宽约束。
- 桌面会议进入全屏后仍显示“退出全屏”；全屏中点击共享屏幕会自动暂退全屏、打开系统选择器，并在授权或取消后恢复原全屏状态。
- 共享授权等待期间按钮保持蓝色可识别状态，不再表现为不可用灰色。Android 重复点击时显示统一的应用内提示。
- Android 多成员视频网格支持纵向滚动与自适应列数，未开启视频的隐藏块不再占用空位。
- Android 升级为 `2.0.0-preview.18 / 2000018`；桌面、Android、服务端和五个平台下载包同步发布。

## 验证与发布

- 根模块 short 测试、静态检查、Relay 9 位额外参会者回归和 42 项窗口/弹窗回归通过。
- Windows 两客户端真实原生集成耗时约 93 秒并通过，覆盖真实会议声流、主持权转让、全屏退出、全屏发起共享、系统音频轨、录制和会议结束。
- Android 单元测试、lint、四 ABI 构建、APK v2 签名和 16 KiB 对齐通过。Linux revision 17 在 Ubuntu 24.04 构建；macOS revision 17 在真实 Mac 上完成双架构打包和严格深度验签。
- 2026-09-13 09:46（北京时间）完成带回滚保护的原子部署，当前 PID 5668。数据库、配置和 TLS 证书未被替换；健康检查、未认证后台 401、数据库完整性、TCP/UDP 监听和日志检查均通过。
- Windows、Linux、两种 macOS 与 Android 安装包都从 `www.yucg.cn:8235` 公网地址完整重新下载，哈希与发布清单一致；Android Range 响应为 `206`。

macOS 安装包仍没有 Apple Developer ID 签名或公证，Android 仍使用预览调试证书。系统屏幕选择器由 Windows/macOS/Android 提供，其内部弹窗样式不受 YuDesk 控制。

## 上一批：冷启动稳定更新

部署批次：`cold-start-20260913.11`

## 用户可见变化

- Windows 被任务管理器强制结束后再次打开，不再复用带崩溃状态的浏览器配置，也不会显示 Edge/Chromium 的恢复提示。
- 无标题栏窗口等到页面和样式真正可绘制后再显示，避免短暂白框、裸浏览器标题栏或未排版页面。
- 重复双击仍只恢复一个主进程和一个界面；连接历史、设备身份和应用设置由 Go 保存，不依赖临时浏览器缓存。
- 桌面、官网和 Android 关于信息统一为“遇到问题联系 17739798184”。
- Android 升级为 `2.0.0-preview.17 / 2000017`；远控、横屏全屏、会议、声流和授权共享能力保持不变。

## 安全与稳定性

- 每次冷启动创建新的 `renderer-*` 专用配置，正常退出与下次启动只清理应用缓存根目录的直接子目录，不触碰用户浏览器或其他路径。
- Chromium 启动继续由私有进程组管理；窗口显示前依次验证目标页面、样式资源、内容 HWND、固定尺寸和嵌入关系。
- 原生窗口关闭、最小化、显示与重复唤醒继续串行处理，短时间重复请求会合并，避免并发创建或显示两个窗口。
- 正式部署脚本在停服前连续检查两次参与连接和活动会话，发现正在使用时立即取消发布；失败路径仍恢复旧程序、配置及下载文件，数据库不被发布包覆盖。

## 构建与发布验证

- 全量 Go 测试和静态检查通过；Windows 真实 Edge 原生窗口连续三轮通过冷启动无裸窗口、渲染器重启无闪窗、样式完成前不显示。
- Android 四 ABI Go 核心、Java 单测、lint、APK v2 签名和 16 KiB 对齐通过。
- Linux revision 16 在 Ubuntu 24.04 构建；macOS Intel 与 Apple Silicon revision 16 在真实 macOS 主机构建，并通过包展开、架构与应用深度验签。
- 2026-09-13 07:58（北京时间）完成带备份的原子部署。五个平台安装包从公网完整下载后与本地产物哈希一致，Android Range 下载返回 `206`；服务端健康检查、数据库完整性、管理页未认证保护及 TCP/UDP 监听均通过。

macOS 安装包没有 Apple Developer ID 签名或公证，Android 仍使用预览调试证书。自动化通过不替代全部品牌 Android 手机及不同 Linux/macOS 桌面的长期真机验收。
