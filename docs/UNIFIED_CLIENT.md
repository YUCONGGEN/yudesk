# 合并客户端（2026-09-08）

## 界面与运行

- 每个平台公开一个 `yudesk` 程序，Windows 为 `yudesk.exe`。无需账号登录、单独被控端、控制端或更新工具。
- 主进程直接运行 `internal/agentapp` 和 `internal/viewerapp`，没有启动另一个 YuDesk 子进程。`cmd/yudesk-agent` / `cmd/yudesk-viewer` 保留薄入口，供旧命令和兼容测试使用。
- 同一个本地监听端口和窗口贯穿首页、连接中、会话和返回首页。复用原单实例锁和身份目录，重复启动唤起原实例。
- 浅色紧凑首页提供本机身份、接收开关、控制/观看、可选声音、设备列表、文件授权、隐藏和退出。授权码输入默认折叠。
- 设备列表在本地保存，最多 30 条，可添加、搜索、移除；不会保存 PIN。远端在线状态每 30 秒局部刷新。本机状态单独刷新，不替换页面结构。
- 会话也采用浅色紧凑样式，画质、网络、剪贴板、文件区与首页统一；工具栏按钮按文字宽度布局，画面完整适配可用空间，设置可收起。
- “结束控制”保留整个程序及本机接收能力；关闭最后一个窗口/首页退出结束进程。隐藏会暂停关窗退出检测，重新打开后恢复检测。
- 后台禁用、删除、断开以及已生效授权到期，会停止整个合并进程。普通临时断网使用退避重连。

## 九位码与旧身份

`device_codes` 为已有 Ed25519 设备身份分配随机九位数字别名，数据库唯一约束阻止冲突；删除设备后号码保留占位，不分配给另一设备。数据库打开时为旧设备补齐号码，不改变原授权和密钥。

客户端通过已验证证书的 TLS 8233 查询九位码对应的完整身份，然后按原完整身份执行端到端签名握手。普通 HTTP 状态页不是身份验证依据。查询有按 IP 的速率限制。

默认 PIN 为六位数字，含前导零；旧默认 PIN 若不符合六位数字，在升级加载时生成并保存新的 PIN。不会变更设备密钥。旧客户端仍能使用原完整身份与服务器通信；要使用新界面和统一 PIN 规则，两台电脑都应更新。

## 接入暂停与失效连接

暂停接入取消待配对的连接或关闭已连接通道。服务器持续读取待配对连接，立即处理 EOF/TLS close_notify，不再只靠十秒心跳发现失效连接。

等待读取通过有背压的内存管道衔接到转发，保留提前到达的握手字节，不让状态探测和远控争抢读取同一个连接。等待端关闭时清除匹配的设备/会话记录，避免短时显示“可连接”却配对到旧通道。

## 验证

- 全量 `go test -race ./...`、`go vet ./...`；中转配对/关闭回归重复 15 轮。
- Node 输入队列、变化区域帧解析、状态查询：10 项通过。
- Windows 原生进程：旧入口兼容生命周期 10 项、合并版生命周期 5 项通过，包括禁用重启拒绝、删除退出、断网到期、关窗退出、隐藏重开。
- 两个独立合并程序在隔离本机 TLS 中转/数据库中完成九位码解析、PIN 验证、真实桌面接收、暂停/恢复、返回首页、设备列表与紧凑响应式界面检查。
- 无界面浏览器验证按键、组合键、IME 和拖动事件序列，截获输入接口，不向本机操作系统注入鼠标键盘。浏览器文件上传/下载使用真实协议通道并核验每个字节。
- 四平台交叉构建完成。macOS/Linux 图形权限、实机桌面输入、异地弱网和长期负载仍需单独验收；不宣称达到零延迟或保证稳定 30 FPS。

## 发布与升级

下载：<http://www.yucg.cn:8235/>。管理页面仍在 HTTP 8235，中转仍在固定证书 TLS 8233，不依赖公网 80/443。

先退出旧程序，重新下载对应平台的 YuDesk；两台电脑都替换。只刷新旧程序页面不会更新内嵌界面。旧 Agent/Viewer 下载链接重定向到统一程序。

服务器发布目录 `releases/20260908-unified-v1`，备份目录 `backups/20260908-unified-v1`，保留旧服务端、下载目录和停服后数据库备份。回退二进制时无需删除新增别名表，禁止覆盖部署后新增的用户数据。
