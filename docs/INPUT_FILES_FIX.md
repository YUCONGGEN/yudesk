# 输入与文件修复候选版（2026-09-07）

本地构建标识：`desktop-input-files-v3`。四个平台各两个客户端在 `dist/`；尚未部署公网、未推送 Git。已更新两端的本机 UI 版本检测，避免重新双击新版时继续复用旧版后台程序。

## 本轮修复

- 之前单个输入错误会从 Agent 会话处理函数退出，连带关闭画面和鼠标。现改为受限频率的输入错误/恢复通知，继续接收会话消息。
- 成功注入的按键才记录为已按下；失败的释放保留待释放状态，后续输入前重试。Windows 键盘按物理 Code 匹配，覆盖标点、修饰键左右侧、小键盘；中文输入法提交文本走 UTF-16 Unicode 注入。无效键和 Process/Dead 等输入法占位事件不再使鼠标失效。
- 前端恢复发送队列在错误清理期间新入队的输入，保留下压—拖动—松开顺序。远程会话页移除“退出控制端”，保留“结束控制”返回连接页。
- 文件与剪贴板等慢操作移出输入读取循环，进入有界工作队列；输入、帧 ACK、ping 不等待磁盘任务。写入仍共享加密 TCP，但文件每块仅 32 KiB，不再把整份文件编码成 Base64 写入同一条通道。
- 传输采用逐块偏移确认、逐块 SHA-256 和完整文件校验。Agent 只在本机明确授权目录中操作，限制路径和文件大小、禁用覆盖，取消/超时/正常断连清理所属临时文件；快速撤销再授权也不会复活旧传输。
- 网络发送的排队等待计入超时；仅在队列中超时不会关闭健康会话，已经开始写入但中断的加密记录仍必须关闭连接，防止后续流解析损坏。
- 切换画面设置时等待上一帧安全结束；若旧写入超过 7 秒仍无法结束，会关闭已卡住的连接，不让文件和设置工作队列永久挂起。
- Linux/macOS 外部截图、输入、剪贴板助手有 5 秒截止时间；Windows 剪贴板助手不弹出命令行窗口。

## 限制与交付注意

两端都要更新才能使用新版文件传输。默认只开放本机授权的 `Downloads/YuDesk`；上限 1 GiB，32 KiB 顺序块优先让出交互通道，高 RTT 下文件吞吐会受限；没有断点续传。原子保存要求目录支持硬链接。强制杀进程或磁盘失败可能遗留本会话临时文件，程序不会扫描删除其他会话文件。

下载支持保存对话框的浏览器走流式落盘并提供页面进度、取消；其他浏览器走其下载列表。不在浏览器堆内存中创建整个文件 Blob。最终校验未通过的响应不会标记成功。

没有绕过 Windows UIPI/UAC；受保护或管理员窗口仍可能拒绝输入，客户端会提示。本轮验证了原生输入记录构造和浏览器事件流，没有在第三方真实机器上操纵鼠标、输入法或管理员窗口，不能宣称所有输入权限场景已验收。

当前仍是区域 PNG/JPEG 与端到端加密 TCP，不是 WebRTC 或硬件视频编码。当地测试帧率/RTT 不能等同公网表现，不能承诺零延迟、固定 30 FPS 或不存在其他缺陷。
