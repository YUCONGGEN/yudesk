# 2.0.0 跨平台安装与响应更新

本轮源代码与最终包的集成记录；已部署为 `installed-20260909.1`，发布日期及下载校验值见 [发布状态](RELEASE_STATUS.md)。本地早期候选及中间安装包不作为最终下载。

## 平台范围

- Windows：默认推荐安装版，明确确认后请求管理员授权；安装成功且版本一致才自动切换。自有原生宿主去掉系统标题栏，保留隐藏、最小化、关闭及拖动。取消授权不偷偷安装。
- macOS Intel / Apple Silicon：安装包把 Go 主程序与原生窗口组件安装到 `/Applications/YuDesk.app`，使用 AppKit/WKWebView，不以裸 Go 可执行文件冒充完整 GUI 包。Go 工具链产物实际要求 macOS 13+。开发者签名、公证尚未完成；被控输入还需要单独准备 `cliclick` 和系统授权。
- Linux x64：提供 `.deb` 与桌面菜单、图标、原生 GTK/WebKitGTK 窗口。依赖解析以 Ubuntu 22.04/24.04、Debian 12/13 为目标，完整被控输入限 X11；不是所有发行版及 Wayland 桌面的兼容承诺。
- Android：APK 安装版、NoActionBar；本轮最终候选是 `2000005 / 2.0.0-preview.5`。系统状态栏、屏幕共享授权及持续通知继续保留。iOS 和原生鸿蒙暂停，不将 APK 称为原生鸿蒙应用。

Unix 包不会安装隐藏自启动、更新服务或 root 远控服务。一个应用实例只有一个 Go 主进程，但原生窗口、系统 WebView、Windows 服务等可具有其自身的辅助进程；不宣称任务管理器永远只有一个操作系统进程。

Mac 应用由接收 Finder 重新打开事件的 AppKit launcher 启动 Go 核心；安装标记位于 `Contents/Resources/yudesk-install.json`，不放在系统当作可执行代码处理的 `Contents/MacOS` 目录。完整资源封装及三个可执行文件采用 ad-hoc 签名，安装包展开后严格验签通过；这不构成 Developer ID 签名或公证。

## 响应与稳定性

- 桌面系统输入使用独立有界工作队列，画面尺寸通过原子值发布，慢输入不占据协议读取或采集尺寸锁。仅合并无按键按下时相邻悬停事件，保留拖动和释放顺序；超过容量时明确结束会话并释放输入，而非无限积压。
- Android 的 Go/Java 输入队列及触点采样统一为仅合并 hover，逐点保留拖动。解码交接仅保留一张最新待显示帧与一个 UI 回调；节拍窗口末尾补采最后画面，避免画面静止后停在旧帧。
- Unix 窗口通过匿名管道管理，不把本机 UI 令牌传入参数或环境；限制消息大小、同源页面导航与窗口故障重试。意外窗口进程退出不等于用户退出，再次打开可恢复窗口。
- 为旧系统 WebView 补齐经过特性检测的请求超时与组合取消接口，避免文件与声音操作因缺少 API 失效。原生文件选择器仍由系统提供；应用确认使用自定义 HTML 对话框。
- 保留身份/PIN/本机审批之后 P2P 优先、初始打洞失败中转，以及独立管理通道；未取消加密、拥塞控制或管理授权来制造低 RTT 数字。

## 本轮验证与边界

Linux 全量 Go 测试与 vet、核心 race、Windows 交叉 vet、Windows 本机原生窗口/安装版本/会话生命周期回归、Mac arm64 上的安装标记/匿名管道/会话生命周期测试通过。最终 Windows 候选包通过统一端隔离联调，包含真实桌面读取、设备列表、PIN 同步、连接审批、服务接口模拟和返回首页；安装模拟不会触发真实管理员安装。14 项弹窗/窗口前端测试及 23 项输入/画面/文件/声音/兼容性测试通过。官网五种视口（320～1440px）的下载入口、图片、布局和键盘操作检查通过。

Ubuntu 22.04/24.04 的真实 WebKit 图形回归通过，包括开启沙箱后的窗口状态、中文复制、拒绝剪贴板读取与文件下载。最终 production helper 与 Go 核心的隐藏/最小化复用、窗口异常后恢复和退出回收集成通过。Mac 离屏 API 与真实 LaunchServices 的无窗口假核心测试通过：三次重新打开保持一个核心实例，核心退出后 launcher 退出；并不等于 Mac 真实远控图形验收。

发布前新增的真实页面检查复现 Linux WebKitGTK 2.50.4 在 DOM 全屏路径中中止进程。最终 Linux helper 改用本机可信操作触发 GTK 原生窗口全屏，保留工具栏；三轮进入/恢复、隐藏复用和 Esc 退出通过，非可信合成点击不能进入全屏。没有把禁用按钮或跳过崩溃测试当作修复。Mac 单独开启系统 WebKit 的公开全屏偏好，未改变 Windows/Android 的窗口实现。

Android 四 ABI 构建、Go race 三轮、29 项 Java 测试、lint、签名与 16KB 对齐检查通过，签名与官网 preview.3 相同。没有 Android 真机验收。Linux/Mac 原生窗口与安装包验证细节分别见 [原生窗口](UNIX_WINDOW.md)、[安装器](UNIX_INSTALLERS.md)。

授权自然到期回归重复执行时曾观察到约 1.6ms 的墙钟/计时截止边界差异。仅为测试观察增加最多 10ms 容差，并仍验证到期后新连接被拒绝；生产授权期限、断开与准入逻辑没有放宽，修正后连续 12 轮通过。

100ms 网络往返时间不会因这些排队修复自动消失。本轮桌面合成画面基准没有证明正常 100ms 链路下平均值明显改善；明确收益是避免已确认的额外阻塞和旧帧/旧事件积压，不承诺零延迟或固定 30FPS。详见 [桌面实测](DESKTOP_INSTALLED_LATENCY_20260909.md)、[Android 专项](ANDROID_LATENCY_20260909.md)。

尚待真实 Windows 管理员安装/锁屏验收、Android 厂商与版本矩阵、Mac Intel 图形操作、跨外网长时间弱网测试。macOS 系统声音和 Android 文件/系统声音能力未在本轮补齐；未把自动化或依赖解析测试冒充完整真机验收。
