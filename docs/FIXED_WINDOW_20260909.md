# 固定窗口与会话工具栏验证（2026-09-09）

本轮保持产品版本 **2.0.0**，桌面安装包 revision 为 **6**。普通桌面窗口固定为 860×600 逻辑像素，禁止用户拖边缩放和最大化；移动窗口、最小化、隐藏主界面以及用户主动整屏显示仍可用。窗口无系统标题栏，客户区贴合四边，不加入黑色填充或裁剪边。

界面同步调整：左上角 YuDesk 标识可点击并在当前窗口返回“远程控制”首页；进入远程会话时“会话设置”默认收起；会话工具栏移除“隐藏”和“×”，只保留最小化，结束本次连接使用明确的“结束控制”。主界面仍保留隐藏、最小化和关闭。

## 平台实现

- Windows：宿主移除 `WS_THICKFRAME` 与最大化能力，固定最小/最大跟踪尺寸，并拒绝系统缩放/最大化命令；DPI 切换仍接受系统建议尺寸以保持相同逻辑大小。
- Linux：GTK/X11 普通状态使用相同的最小/最大几何限制，移除四边 resize drag；进入原生全屏前临时解除限制，退出后恢复 860×600。
- macOS：AppKit 窗口移除 `.resizable`，内容最小/最大尺寸同时设为 860×600；仍保留最小化及 WebKit 的用户主动整屏能力。
- Android：Activity 由手机屏幕与横竖屏决定，不存在桌面窗口拖边或系统标题栏，本轮 APK 保持 preview.5，不伪造固定桌面尺寸。

## 验证结果

- 全量 Go short 测试通过；输入错误恢复测试改为等待异步输入事件与 ping 均到达，避免把跨队列合法乱序误报为失败。
- Windows 真实隔离 Chromium 宿主通过：客户区与外部窗口四边一致、没有系统框，固定尺寸跟踪值一致，系统最大化命令不改变窗口；导航、最小化/恢复和十次隐藏/显示继续通过。
- 42 项独立窗口/弹窗测试通过。最终 Windows GUI EXE 的双端统一联调通过：左上角标识点击回首页、远程设置默认收起、会话隐藏/X 不存在、最小化存在，真实画面、审批、PIN、结束控制返回首页均通过。
- Linux 在 Ubuntu 24.04 隔离 X11/WebKitGTK 中真实验证：窗口管理器尝试改为 1000×700 后仍为 860×600；最小化/恢复、四次真实拖动、三次 1280×800 全屏/恢复、下载、中文剪贴板与渲染器恢复通过。Ubuntu 22.04 构建并检查 revision 6 安装包。
- macOS 在真实 Mac SDK 上编译 Intel/Apple Silicon 原生 helper 和 launcher；arm64 helper 自检通过，两个 revision 6 安装包完成展开、架构检查及 ad-hoc strict/deep 验签。没有在两种 Mac 图形桌面上手工拖边验证。

固定窗口是界面行为调整，不改变 P2P/中转、画面编码或物理网络 RTT。Android 包、设备身份、PIN、授权、数据库和服务器端口均不迁移。最终上线时间、下载校验值和 GitHub Release 见 [当前发布状态](RELEASE_STATUS.md)。
