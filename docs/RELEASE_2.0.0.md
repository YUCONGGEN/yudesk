# YuDesk 2.0.0

桌面统一客户端版本为 `2.0.0`。发布网站从经过校验的 `downloads/release.json` 读取版本和实际发布时间，统一显示北京时间，不把文件复制时间当成发布日期。下载文件名包含版本和平台，旧下载地址保持兼容。

## 功能

- 只填设备码可请求连接：被控端明确同意才允许本次控制或观看，60 秒未操作自动拒绝。错误 PIN 不降级为审批；可继续用正确 PIN 连接。
- 请求为单次授权，每台设备同时只有一条，每分钟最多三次。取消、断线、过期、停止接收或退出后旧审批失效。隐藏中的窗口收到请求会重新显示。
- Windows 去除系统标题栏；内部按钮顺序为隐藏、最小化、关闭。最小化保留任务栏和蓝色 Yu 托盘图标；隐藏同时收起窗口、任务栏和托盘；再次双击程序或隐藏时同时按 Ctrl+Y+U 恢复。
- 所有 X / 退出关闭主应用；“结束控制”只返回主界面。关闭时释放输入及连接，不生成退出结果页。
- 软件的确认弹窗使用自定义样式，后台危险操作保留明确确认和 CSRF 校验。管理员授权及屏幕共享等操作系统权限框不被替代。
- 官网采用留白、浅蓝的产品展示排版，下载区后展示项目简介、三张真实客户端界面的脱敏演示截图、使用流程和平台限制。静态资源随服务器内嵌，无外部 CDN；不展示真实电脑桌面或实际设备凭据。

## 验证与限制

- Go race/vet、Windows 交叉检查；协议审批接受/拒绝/过期/取消/错误 PIN；本机真实加密双客户端 60 秒超时与控制/观看分离测试。
- 前端 34 项测试、统一客户端真实本地联调，验证无浏览器默认弹窗、请求审批、PIN 更换与同步、返回首页、分页和紧凑按钮顺序。输入测试不操作用户真实鼠标键盘。
- Windows Chrome / Edge 窗口几何验证顶部系统标题栏不再占高度；托盘注册、隐藏、恢复、退出清理测试。操作系统可能把新托盘图标放到折叠菜单内。
- macOS/Linux 编译并复用审批和界面功能，但尚未实现对应平台系统托盘、全局快捷键或无系统标题栏；完整真机验收仍待完成。
- 安卓是单独标注的预览版，需 MediaProjection 与无障碍授权；不能承诺所有品牌/旧系统/受保护画面均可操作。iOS 暂停。安卓实际编译和验收状态见 `docs/ANDROID.md`，没有 APK 时网页不会提供有效下载。
- 网站按要求使用 HTTP 非标准端口；后台密码与下载来源仍存在明文 HTTP 的安全限制。远程画面和输入使用经过固定证书校验的中转连接及客户端间端到端加密。

部署状态以 `docs/RELEASE_STATUS.md` 与线上验证记录为准；本说明不是未完成平台的验收证明。
