# 健壮性检查与时间修复（2026-09-08）

## 本轮修复

- 文件目录请求增加取消、25 秒超时及任务归属检查。切换目录先清除旧可点击项，迟到的响应/错误不覆盖新目录；读取中禁止启动传输。关闭页面取消未完成请求。
- 浏览器下载拒绝缺少大小、超过 1 GiB 或实际超出声明长度的响应，不提交临时文件；释放读取器。后端仍逐块及整文件 SHA-256 校验、限定共享目录、拒绝覆盖同名文件。
- 声音状态查询串行化，慢请求不会叠加定时请求；旧播放任务不会关闭新播放任务。已取消的 HTTP 监听者不会重新启动远端采集。
- 音频 HTTP 写超时仅用于实际写入/刷新，随后清除。修复静音超过 2 秒后可能因旧写截止时间导致下一次播放失败的问题；刷新失败及时退出并停止按需采集。
- 后台时间明确使用北京时间 UTC+8，统一最后在线、授权到期、审计、数据刷新及授权提示。生产主机原使用 PDT，相比北京时间相差 15 小时；不改变主机全局时区。
- 设备管理通道每次收到通过身份认证后的 `pong`，记录真实响应时间；后台直接读取该时间，每 15 秒落库、连接退出时保存最后响应。旧连接清理不能回退时间，删除后迟到的心跳不能重建设备。授权兑换不再修改在线时间。

后台仍是每 30 秒异步刷新，不跳页；编辑时暂停。网络异常的在线判定仍有约 12 秒心跳超时窗口，页面状态还受刷新间隔影响，不等于即时断线检测。异常强杀服务器可能丢失最后约 15 秒心跳落库；旧版本未记录的历史心跳无法恢复，不编造历史离线时间。

## 界面标识

本机 PIN 的眼睛按钮右侧增加同款循环箭头。点击使用密码学随机数生成不同于旧值的 6 位 PIN，先写临时文件并同步落盘再替换，成功后更新内存，设备私钥、设备码和授权不变。后续握手即时拒绝旧 PIN；已认证的会话不中断。管理心跳携带新 PIN，服务端数据库提交成功后回传确认，主界面显示同步成功；后台沿用每 30 秒异步刷新，也可立即刷新。离线期间允许本机更换，恢复管理连接后重传；未收到服务端确认不会显示“已同步”。

## 验证与限制

新增自动化覆盖迟到目录成功/失败、取消页面请求、异常下载大小、音频慢查询、静音恢复、取消监听、显式时区、心跳落库/清理、离线时间不可被后台刷新及授权修改污染，以及标识和本地资源。

Go 全量 race、vet 和 Windows 交叉 vet；20 项 Node 回归；Windows 原生进程生命周期、合并界面、真实桌面/加密声音及文件传输回归。界面验证含 860×562 内容区域及窄屏、备案居中、服务按钮不被裁切、会话 X 返回首页。实际发布结果及文件哈希见 [发布状态](RELEASE_STATUS.md)。

本轮改善的是已定位缺陷，不是“永不卡”保证。性能基线见 [响应实测](LATENCY_20260908.md)。当前仍是 TCP 中转与 JPEG/区域编码，弱网队头阻塞和尾延迟没有完全消除；尚未实现硬件 H.264/AV1、WebRTC/QUIC 或 Opus 音频。

Windows 系统声音在本机加密链路验证；不是两台公网真机听感验收。未主动锁屏/解锁、输入系统密码或注入开发主机真实鼠标键盘。macOS 系统声音不支持；Linux 图形与声音、macOS 完整远控未做本轮真机验收。持续数日的长稳、丢包/带宽抖动矩阵及大规模设备容量尚需专门验收。

网站仍按用户要求使用 HTTP。中转 TLS 固定证书及端到端加密不能保护明文后台认证与下载来源；公网生产使用仍应另行解决这一安全边界，不能据此宣称完整生产级安全。
