Install YuDesk

YuDesk will be installed in Applications. After installation, open Applications and double-click YuDesk.

Your saved device identity and preferences remain in your user account. This installer does not launch YuDesk or enable login items or background services.

If YuDesk is already open, save your work and close it when convenient. Installation does not end an active session; the updated version is used after you reopen the app.

Allowing another device to control this Mac additionally requires a compatible cliclick input tool provisioned by your administrator and macOS Accessibility permission. This installer does not include cliclick, so it does not provide all remote-input features on a clean Mac.

YuDesk 将安装到“应用程序”。安装后双击 YuDesk 即可打开。设备身份与设置保留；安装不会启动客户端，也不会启用开机自启或后台服务。

此安装包不含 cliclick。允许其他设备控制本机还需要管理员提供兼容的 cliclick 输入工具并授予“辅助功能”权限；全新 Mac 不能保证开箱支持全部被控功能。
