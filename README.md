# YuDesk

YuDesk 是一个 Go 语言实现的跨平台远程桌面项目。普通用户不需要注册账号、登录账号或输入命令；每个平台只提供两个程序：

- **YuDesk 被控端**：在需要被控制的电脑上双击运行。
- **YuDesk 控制端**：在控制电脑上双击运行，输入设备码和临时 PIN 后连接。

官网与下载地址：<http://www.yucg.cn:8235/>

管理员后台：<http://www.yucg.cn:8235/admin>

## 用户使用方法

### 被控电脑

1. 打开官网，选择当前系统的“YuDesk 被控端”。
2. 双击运行程序。
3. 程序会自动打开本机页面，显示设备名称、设备码、临时 PIN、联网状态和授权有效期；设备码、PIN 可分别一键复制，也可以一次复制两项。
4. 首次使用时，将设备码发给管理员，由管理员直接授权；也可以填写管理员发放的限时激活码。
5. 将设备码和临时 PIN 发给控制方。

点“隐藏到后台”只隐藏页面并继续在线，再次双击程序会重新显示原来的进程；直接关闭被控端浏览器窗口则会自动结束进程。同一用户下只会保留一个被控端进程。已生效的设备授权到期，或管理员执行断开、禁用、删除时，被控端会重新弹出状态页并自动退出，包括断网期间到期。未授权或已过期设备重新运行时可保留页面等待激活。

### 控制电脑

1. 打开官网，选择当前系统的“YuDesk 控制端”。
2. 双击运行程序。
3. 输入对方的设备码和临时 PIN，选择“控制”或“仅观看”，并按需勾选“听取被控端声音”，再点击“连接远程电脑”。
4. 连接成功后自动打开可视化远程桌面。画面会完整适配窗口，点击“整屏显示”进入全屏。双击画面会按正常双击发送给远端，不再抢占远端双击操作。

关闭控制端浏览器窗口会自动断开连接并结束控制端进程。点击远程画面上的“结束控制”也会关闭连接和后台进程；连接页面提供“退出控制端”按钮。连接页面和远程控制在同一个控制端进程中运行，重复双击不会产生多个控制端进程。

控制模式支持鼠标移动、点击、拖动、右键、滚轮、键盘、组合键、剪贴板和授权目录文件上传，被控电脑本机鼠标仍可同时操作。仅观看模式由被控端会话强制拒绝输入、剪贴板写入和上传。声音是可选项：Windows 使用 WASAPI 采集系统播放声音，Linux 在安装 PulseAudio 的 `pactl`/`parec` 后可用；浏览器要求进入桌面后点击一次“播放声音”。macOS 系统声音采集尚未提供。

### 帧率、传输与连接记录

- 画面设置提供固定和自适应模式，目标帧率 1–60 FPS；固定模式保持指定画质，自适应模式在处理或传输过慢时降低画质。实际帧率受截图速度、电脑性能和网络限制，不能保证在所有机器上达到目标值。
- 默认采用原始分辨率、固定 30 FPS 目标、画质 82，不设置画面带宽上限；也可一键切换 960 宽低延迟档，或选择最大宽度 1920/1600/1280/960/640。画面保持比例，鼠标坐标会换算回远端原始分辨率。可设置带宽预算和静止省流，设置保存在控制端本机。
- 新版客户端最多允许两帧等待接收确认，静止画面不重复发送（约 5 秒保活一次），避免旧截图持续积压。带宽预算针对画面载荷，不是包含全部协议开销的网卡硬限速。
- 顶部显示实际接收帧率、应用层往返延迟 RTT 和下行速率；侧栏显示上下行速率、累计流量、分辨率和实际画质。RTT 包含中转、处理和排队，不能等同于单程画面延迟。
- 控制端保存最近 30 台成功连接的设备名称、设备码和时间，支持再次填入设备码、移除记录；不保存 PIN 或登录令牌。
- 鼠标移动合并发送，但按下、拖动和松开严格按顺序传送。页面失焦、取消指针或会话断开时释放本会话按住的鼠标和键盘按键。

这些功能需控制端、被控端都更新。Windows 完成了真实截图、帧率/RTT、设置切换和连接记录回归；鼠标坐标与输入顺序有自动化测试。Linux/macOS 仍依赖各系统桌面工具和权限，实际高帧率及图形输入需要对应真机验收。

## 管理员后台

管理员使用浏览器进入 <http://www.yucg.cn:8235/admin>。后台拥有全部设备与授权管理权限：

- 状态总览显示当前在线、连接中、在线待连接、离线、设备总数和需要处理的授权数量；
- 设备、授权码和审计记录均支持服务器端条件查询和独立分页，并在操作后保留当前查询页；
- 查看授权状态、有效期、最后连接时间和经过设备身份验证后上报的 PIN，并可一键复制；
- 修改设备名称；
- 按天或小时直接授权、续期，并可单独解禁设备；
- 可开启“新设备免激活”，让连接服务器的未授权被控端自动获得永久授权；关闭后，新设备仍必须输入激活码或由管理员授权，禁用设备不会被自动解禁；
- “断开并退出”会断开在线连接并终止当前被控端进程；
- “禁用并退出”会终止当前进程，且该设备下次运行会被拒绝；
- “删除并退出”会终止当前进程并删除记录，再次运行时需要重新授权；
- 按时长批量生成激活码；
- 吊销未使用的激活码；
- 查看全部管理和连接审计记录。

在线状态每 30 秒异步刷新，只替换状态数据，不重载页面，也不改变滚动位置、分页查询和筛选条件；编辑表单期间自动暂停。管理员密码保存在服务器的 `data/admin.key`，不写入源码或公开下载文件。

新版被控端在同一进程内保持独立的、经过设备身份验证的管理连接，复用中转端口 8233；不增加进程或公网端口。等待配对和正在远控时都可以接收退出指令，退出会同时关闭管理连接、远控连接和本地网页。普通网络故障采用退避重连；收到服务器明确拒绝、禁用或退出指令后不重试。此处“断开”只结束 YuDesk 远程连接，不禁用电脑网卡或其他软件的网络。旧版程序必须替换后才能具备这些行为。

## 平台支持

| 平台 | 架构 | 被控端 | 控制端 |
| --- | --- | --- | --- |
| Windows 10/11 | x64 | `yudesk-agent.exe` | `yudesk-viewer.exe` |
| Linux Desktop | x64 | `yudesk-agent` | `yudesk-viewer` |
| macOS Intel | x64 | `yudesk-agent` | `yudesk-viewer` |
| macOS Apple Silicon | arm64 | `yudesk-agent` | `yudesk-viewer` |

Windows 版本采用 GUI 子系统构建，双击时不会出现黑色命令行窗口。macOS 首次运行需要在“系统设置 → 隐私与安全性”中授予屏幕录制和辅助功能权限。Linux 需要图形桌面，并依赖系统可用的截图与输入能力。

## 网络与安全

```text
控制端 ── TLS ── www.yucg.cn:8233 ── TLS ── 被控端
                第三方中转服务器

控制端 ═════════ Agent ↔ Viewer 端到端加密 ═════════ 被控端
```

- 中转服务器只转发远程会话；远程画面、声音、输入、剪贴板及文件数据使用 Agent 与 Viewer 之间的端到端加密。
- 客户端内置并校验服务器 TLS SHA-256 指纹，默认不接受伪造的中转服务器。
- Viewer 提交的 PIN 在端到端加密通道内由 Agent 验证，并带失败次数限制。为满足管理员查看 PIN 的需求，Agent 还会通过已校验服务器身份且经过设备签名认证的 TLS 管理连接上报 PIN，服务器数据库和管理员可读取它。
- 授权过期或管理员禁用设备后，服务器会拒绝或断开远程会话。
- 客户端的激活请求和中转 TCP 连接不使用环境变量中的 HTTP/HTTPS 代理，避免占用代理流量。

官网和管理员后台按要求使用普通 HTTP。HTTP 不能保护管理员密码、设备码、PIN 和激活码在传输过程中的机密性；不要在不可信 Wi-Fi 或存在流量监听的网络中登录后台。

## 构建与测试

本机安装 Go 1.22 或 Docker 后，可构建四个平台：

```powershell
.\scripts\build.ps1 -Target all
```

Linux/macOS：

```sh
./scripts/build.sh all
```

服务器程序单独输出到 `dist/server/yudesk-relay`；公开下载目录只发布四个平台各两个客户端。`dist/SHA256SUMS.txt` 记录公开客户端的 SHA-256。

测试命令：

```sh
go test ./...
go test -race ./...
go vet ./...
node --test scripts/input.test.cjs
```

测试覆盖设备身份、限时授权、管理员操作、Relay 长连接、端到端握手、PIN 验证、协议限制、下载白名单和本机网页访问令牌。发布前还需在真实 Windows、Linux 与两类 macOS 机器上完成图形权限和远控输入验收。

真实进程生命周期回归使用独立的本机中转服务、临时数据库和测试设备，不访问线上管理接口。设置 `YUDESK_CLIENT_DIR` 为当前操作系统的客户端构建目录，然后运行 `go test ./cmd/yudesk-relay -run TestNativeClientLifecycle -v`。Windows 自动验证收到的桌面 JPEG；Linux/macOS 默认只测进程及通信，有可用桌面和权限时设置 `YUDESK_TEST_DESKTOP=1` 验证图像。测试覆盖重复启动、网页退出、管理员断开/禁用/删除、过期退出及临时网络恢复。

## 服务器部署

服务器文件位于 `~/bin/yudesk`：

```text
~/bin/yudesk/
├── bin/yudesk-relay
├── data/admin.key
├── data/relay.crt
├── data/relay.key
├── data/yudesk.db
├── downloads/
├── logs/
├── server.conf
├── start.sh
├── stop.sh
└── status.sh
```

公网服务：

- `http://www.yucg.cn:8235/`：官网、教程、客户端下载安装包；
- `http://www.yucg.cn:8235/admin`：管理员后台；
- `www.yucg.cn:8233`：远程桌面中转连接。

服务器端只运行 `yudesk-relay`。普通用户下载目录不包含账号工具、命令行管理工具或更新工具。

## 当前限制

当前版本已经能完成真实远程画面、输入和中转连接，但仍不是 ToDesk 的同等成熟实现：

- 画面使用带接收确认的 JPEG 帧流，尚未接入硬件 H.264/AV1 编码；
- Windows 和具备 PulseAudio 工具的 Linux 支持系统声音；macOS 系统声音、多显示器选择和无人值守系统服务暂未支持；
- Windows 已使用原生桌面采集/输入并修复 DPI 缩放裁切；
- Linux/macOS 的桌面权限和输入能力受系统版本及桌面环境限制；
- 未签名的 macOS 程序首次打开时可能需要在系统安全设置中确认。

这些限制不会影响继续开发或内部远程使用，但面向大规模公网商业部署前仍需补充原生编码、签名安装包、自动化真实机矩阵和长期压力测试。
