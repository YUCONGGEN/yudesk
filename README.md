## 用户使用方法

1. 两台电脑都从官网选择对应平台下载 **YuDesk 安装包**。Windows 双击 `.exe` 后会直接进入系统管理员授权，不再重复显示 YuDesk 安装确认或跳转设置页；macOS 使用 `.pkg` 安装到“应用程序”；Linux 使用系统软件安装器打开 `.deb`。安装后从应用菜单打开。网站显示版本与北京时间发布日期；macOS 包尚未签名公证，可能被系统阻止，不要求用户关闭系统安全保护。
2. 需要被连接的电脑开启“允许连接本机”，显示 **9 位数字设备码**和 **6 位数字 PIN**。可分别复制，也可一键复制两项。
3. 首次接收连接需要管理员授权或激活。在“设置”中查看设备授权，点击默认折叠的“输入授权码”展开填写；服务器开启免激活时自动获得永久授权。
4. 另一台电脑输入对方设备码，选择“远程控制”或“仅观看”，按需勾选“听取声音”，点击“连接”。PIN 可选：填写正确 PIN 直接验证；留空则等待对方明确同意，60 秒超时自动拒绝。错误 PIN 不降级成审批。设备码输入后自动检测是否在线，连接前再次检查。
5. “设备列表”支持添加、搜索、移除和再次连接，包含本机、保存的设备及连接历史。在线状态每 **30 秒异步刷新**，不跳页、不滚动，不保存 PIN。
6. 临时共享屏幕可打开“会议”：主持人点“发起会议”，复制生成的 9 位会议号；参与者输入会议号后直接加入。会议是仅观看模式，桌面参与端可按能力听取主持电脑声音；Android 当前不支持系统声音。最多一位参与者同时在线，不要公开发布仍有效的会议号。Android 发起会议会先显示系统屏幕共享授权，Android 参会和普通远程会话自动进入横屏全屏。
7. 连接后的界面使用同样的浅色、蓝色和紧凑布局。设置侧栏默认收起，需要时点击“设置”打开；“整屏显示”进入全屏。画面、延迟、声音、剪贴板和文件传输在同一窗口操作。
8. 点“结束控制”只结束本次会话，自动返回统一首页，本机接收连接能力仍保留。会话内没有“退出控制端”按钮；主持人点“结束会议”会使会议号立即失效并断开当前参与者。

主界面按钮顺序为 **隐藏 → 最小化 → 关闭**。Windows 最小化保留任务栏及蓝色 Yu 托盘图标；“隐藏”收起界面、任务栏和托盘并保持在线，再次双击或隐藏时同时按 **Ctrl+Y+U** 恢复。远程会话顶部不显示“隐藏”和“×”，只保留最小化；“结束控制”返回主界面。主界面的 X / 退出关闭应用。重复启动不会新增主进程或另开一个界面窗口。可选 Windows 系统服务不会随主界面退出而卸载；macOS/Linux 尚无本版的系统托盘和全局快捷键。

桌面普通窗口固定为 860×600 逻辑像素（高 DPI 由系统缩放），不能拖边改变大小或最大化；主动“整屏显示”不受该限制，退出全屏恢复固定尺寸。设备码和 PIN 输入框采用紧凑宽度。页面不横向或纵向滚动，设备列表分页，远程侧栏使用“画面 / 网络 / 剪贴板 / 文件”分栏。Windows 原生宿主需要 Microsoft Edge、Google Chrome 或 Chromium；macOS 使用系统 WKWebView，Linux 安装包依赖 WebKitGTK。主程序和原生窗口组件须一并安装，不能只复制 Unix 的裸可执行文件。详情见 [窗口行为](docs/WINDOW_LIFECYCLE.md)、[Unix 安装包](docs/UNIX_INSTALLERS.md)。

暂停“允许连接本机”会断开本机接收通道，恢复后重新等待连接。管理员断开、禁用、删除或已生效授权到期会终止本机整个程序；过期退出也覆盖断网情况。禁用后再次运行仍会被拒绝，需管理员解禁。

设备码是服务器分配并持久化的唯一短编号；内部 Ed25519 身份和原设备授权不变。短码映射通过校验证书的 TLS 中转查询，再执行完整设备身份的端到端验证。已有身份与连接记录兼容；升级旧版非 6 位数字 PIN 时会生成并保存新的 6 位 PIN。

控制模式支持鼠标移动、点击、拖动、右键、滚轮、键盘、组合键、剪贴板及授权目录文件上传/下载，被控电脑本机鼠标仍可操作。仅观看模式在接收端拒绝输入、剪贴板写入和文件读写。声音是可选能力，受对应平台支持限制。

### 帧率、传输与连接记录

- 首要目标是交互低延迟。默认自适应模式、30 FPS 目标、最大宽度 1280、JPEG 画质 70、画面预算 8 Mbps。检测到 ACK 延迟增长或采集/编码过慢时降低画质、分辨率，稳定后缓慢恢复；可手动选择原始分辨率、固定 30 FPS、画质 82。
- `tiles-v1` 比较原始像素，仅压缩变化的 256×256 区域；平坦界面、文字区域优先无损 PNG，照片类区域采用 JPEG。Windows 无变化区域不再进入 JPEG 编码器。浏览器以 Canvas 合成完整画面，慢消费者合并每个区域的最新版本，重开页面取得完整状态。
- 采集与编码/网络发送并行，等待编码的原始画面只保留最新一张。编码 worker 数量按可用 CPU 限制（最多 4 个，多核时预留调度余量），原始图像与 PNG 压缩缓冲复用；输入读取和普通响应发送独立，避免增加并发却积压旧画面。
- 最多八个区域更新批次等待接收确认；累计未确认载荷达到约 100 毫秒的配置带宽用量时暂停编码/发送下一批（阈值 8 KiB～1 MiB，单个批次可超过阈值，无带宽配置时用 128 KiB），采集继续替换最新等待帧。自适应判断包含预计传输耗时，避免低带宽下只堆积画面。带宽预算针对画面载荷，不是网卡硬限速。
- 静止省流不重复编码或发送画面。自适应模式收到输入后，在 100 毫秒内临时以最高 60 Hz 检查画面变化，减少等待和漏过应用下一次重绘的机会，仍遵守带宽与在途限制；固定帧率模式不启用该提速。关闭静止省流时，未变化帧仅发送少量空更新元数据。
- 顶部显示实际接收帧率、应用层往返延迟 RTT 和下行速率；侧栏显示上下行速率、累计流量、分辨率和实际画质。RTT 包含中转、处理和排队，不能等同于单程画面延迟。
- 控制端保存最近 30 台成功连接的设备名称、设备码和时间，支持再次填入设备码、移除记录；不保存 PIN 或登录令牌。
- 鼠标移动合并发送，但按下、拖动和松开严格按顺序传送。新协议使用不等待远端回包的有序输入事件，下行回包阻塞不再阻塞输入读取。页面失焦、取消指针或会话断开时释放本会话按住的鼠标和键盘按键。

这些功能需控制端、被控端都更新。Windows 完成了真实截图、帧率/RTT、设置切换和连接记录回归；鼠标坐标与输入顺序有自动化测试。Linux/macOS 仍依赖各系统桌面工具和权限，实际高帧率及图形输入需要对应真机验收。

研究依据、测试方法和未实现的硬件视频路径见 [低延迟设计与验收](docs/LOW_LATENCY.md)。线上旧版仍是端到端加密 TCP 中转；当前开发代码新增 WebRTC 数据通道直连及 TCP 回退，不代表已实现 WebRTC 视频编码、QUIC、硬件 H.264 或论文中的学习模型。

## 管理员后台

管理员使用浏览器进入 <http://www.yucg.cn:8235/admin>。后台拥有全部设备与授权管理权限：

- 状态总览显示当前在线、连接中、在线待连接、离线、设备总数和需要处理的授权数量；
- 设备、授权码和审计记录均支持服务器端条件查询和独立分页，并在操作后保留当前查询页；
- 查看授权状态、有效期、最后连接时间和经过设备身份验证后上报的 PIN，并可一键复制；
- 修改设备名称；
- 按天或小时直接授权、续期，并可单独解禁设备；
- 可开启“新设备免激活”，让连接服务器的未授权被控端自动获得永久授权；关闭后，新设备仍必须输入激活码或由管理员授权，禁用设备不会被自动解禁；
- “断开并退出”会断开在线连接并终止当前被控端进程；
- “禁用并退出”会终止当前进程，且该设备下次运行会被拒绝；
- “删除并退出”会终止当前进程并删除记录，再次运行时需要重新授权；
- 按时长批量生成激活码；
- 吊销未使用的激活码；
- 查看全部管理和连接审计记录。

在线状态每 30 秒异步刷新，只替换状态数据，不重载页面，也不改变滚动位置、分页查询和筛选条件；编辑表单期间自动暂停。管理员密码保存在服务器的 `data/admin.key`，不写入源码或公开下载文件。

新版被控端在同一进程内保持独立的、经过设备身份验证的管理连接，复用中转端口 8233；不增加进程或公网端口。等待配对和正在远控时都可以接收退出指令，退出会同时关闭管理连接、远控连接和本地网页。普通网络故障采用退避重连；收到服务器明确拒绝、禁用或退出指令后不重试。此处“断开”只结束 YuDesk 远程连接，不禁用电脑网卡或其他软件的网络。旧版程序必须替换后才能具备这些行为。

## Windows 锁屏控制（可选服务）

Windows 正常首次启动默认推荐安装版。确认应用内提示后仍需 Windows 管理员授权，安装成功自动切换；取消授权不会偷偷安装。也可在“设置 → 安装与锁屏控制”中安装或更新。控制电脑也需要更新，才能显示新的桌面等待状态和设置反馈。

安装版位于 `C:\Program Files\YuDesk\yudesk.exe`；原设备码、PIN 和授权沿用当前用户配置。此模式额外运行一个系统服务和一个当前控制台会话的桌面辅助进程，不再是便携模式的单进程。服务无网络监听，不保存 Windows 密码；关闭主程序后无法继续接收远控，服务本身仍运行，可在设置中卸载。

普通版遇到锁屏/受保护桌面时会保持连接、暂停输入并显示原因，解锁后自动恢复完整画面。可选服务提供受保护桌面的采集/输入通道，但目前仅支持 Windows 本机控制台会话，不支持 RDP 会话、注销后无人值守登录，以及需要 Ctrl+Alt+Del 安全注意序列的登录流程。没有绕过 Windows 密码的功能。原生锁屏解锁输入仍需两台真机验收。

Windows 剪贴板改为原生 Unicode 接口，中文、繁体、表情及多行文本不再经过 PowerShell 控制台编码；受保护桌面期间暂停剪贴板读写。会话中“应用设置”现在显示应用中、成功或失败提示，即使收起侧栏也有浮动提示。

安装、安全边界和测试结果见 [Windows 桌面服务](docs/WINDOWS_DESKTOP_SERVICE.md)。

## 文件传输（新版两端客户端）

1. 在接收连接的电脑打开首页“文件传输”，开启文件授权。默认关闭，授权设置会记住。
2. 默认只共享用户目录下 `Downloads/YuDesk`，页面显示完整路径；要下载的文件先放入这个目录。不会开放整个磁盘。
3. 控制端侧栏选择文件，点击“上传到被控端”；文件列表可浏览子目录及下载。每个文件最多 1 GiB，同名文件不会覆盖。
4. 上传显示进度，可取消；最后校验保存阶段不能撤销。支持系统保存对话框的浏览器可以在页面查看下载进度和取消；其他浏览器使用原生下载列表。
5. 被控端关闭文件授权会使旧传输编号失效，即使马上重新开启也不能续用；正常断连清理本会话的未完成临时文件。强制杀进程、磁盘故障后可能需要本机手动清理临时文件。

采用 32 KiB 二进制分块、逐块及整文件 SHA-256 校验、受限目录和原子非覆盖保存。接收目录需要支持硬链接的本机文件系统；FAT/exFAT 等不支持时会明确报错。没有断点续传；失败后取消并重新传输。两端都需要更新，旧版整文件接口已禁用。实现和验收范围见 [输入及文件修复说明](docs/INPUT_FILES_FIX.md)。

## 网络与安全

以下是认证、管理以及中转回退路径。开发版 P2P 成功后，画面与操作改走双方 UDP 直连，服务器连接仅保留授权心跳；初始打洞失败仍使用此路径。

```text
控制端 ── TLS ── www.yucg.cn:8233 ── TLS ── 被控端
                第三方中转服务器

控制端 ═════════ Agent ↔ Viewer 端到端加密 ═════════ 被控端
```

- 中转服务器只转发远程会话；远程画面、声音、输入、剪贴板及文件数据使用 Agent 与 Viewer 之间的端到端加密。
- 客户端内置并校验服务器 TLS SHA-256 指纹，默认不接受伪造的中转服务器。
- Viewer 提交的 PIN 在端到端加密通道内由 Agent 验证，并带失败次数限制。为满足管理员查看 PIN 的需求，Agent 还会通过已校验服务器身份且经过设备签名认证的 TLS 管理连接上报 PIN，服务器数据库和管理员可读取它。
- 授权过期或管理员禁用设备后，服务器会拒绝或断开远程会话。
- 客户端的激活请求和中转 TCP 连接不使用环境变量中的 HTTP/HTTPS 代理，避免占用代理流量。

官网和管理员后台按要求使用普通 HTTP。HTTP 不能保护管理员密码、设备码、PIN 和激活码在传输过程中的机密性；不要在不可信 Wi-Fi 或存在流量监听的网络中登录后台。

## 构建与测试

源码最低要求 Go 1.25（安全文件目录接口）；本机安装支持工具链自动下载的 Go，或 Docker 后，可构建四个平台。发行脚本和 CI 固定使用 Go 1.27.1，操作系统最低版本也需满足该工具链要求：

```powershell
.\scripts\build.ps1 -Target all
```

Linux/macOS：

```sh
./scripts/build.sh all
```

服务器程序单独输出到 `dist/server/yudesk-relay`；公开下载目录只发布四个平台各一个合并客户端。旧 Agent/Viewer 下载链接会跳转到新客户端，旧源码入口保留用于兼容测试。`dist/SHA256SUMS.txt` 记录公开客户端的 SHA-256。

测试命令：

```sh
go test ./...
go test -race ./...
go vet ./...
node --test scripts/input.test.cjs scripts/frames.test.cjs scripts/presence.test.cjs scripts/audio.test.cjs scripts/files.test.cjs
```

测试覆盖设备身份、限时授权、管理员操作、Relay 长连接、端到端握手、PIN 验证、协议限制、下载白名单和本机网页访问令牌。发布前还需在真实 Windows、Linux 与两类 macOS 机器上完成图形权限和远控输入验收。

真实进程生命周期回归使用独立的本机中转服务、临时数据库和测试设备，不访问线上管理接口。设置 `YUDESK_CLIENT_DIR` 为当前操作系统的客户端构建目录，然后运行 `go test ./cmd/yudesk-relay -run TestNativeClientLifecycle -v`。Windows 自动验证收到的桌面 JPEG；Linux/macOS 默认只测进程及通信，有可用桌面和权限时设置 `YUDESK_TEST_DESKTOP=1` 验证图像。测试覆盖重复启动、网页退出、管理员断开/禁用/删除、过期退出及临时网络恢复。

统一客户端原生回归：设置 `YUDESK_CLIENT_DIR` 为合并版二进制目录、`YUDESK_UNIFIED_TEST=1`，运行 `go test ./cmd/yudesk-relay -run TestNativeUnified -v`。可选设置 `YUDESK_UNIFIED_BROWSER_SCRIPT` 为 `scripts/unified-browser.test.cjs` 的绝对路径，使用本地无界面 Chrome 检查界面、真实桌面、短码连接、暂停/恢复和返回首页；浏览器输入被截获，不操作测试主机的真实鼠标键盘。


公网服务：

- `http://www.yucg.cn:8235/`：官网、教程、客户端下载安装包；
- `http://www.yucg.cn:8235/admin`：管理员后台；
- `www.yucg.cn:8233`（TCP）：远程桌面中转、信令及管理连接；
- `www.yucg.cn:8233`（UDP，待部署验证）：开发版 P2P 的 STUN 绑定发现，需要单独开放/映射 UDP。

服务器端只运行 `yudesk-relay`。普通用户下载目录不包含账号工具、命令行管理工具或更新工具。

## 当前限制

当前版本已经能完成真实远程画面、输入和中转连接，但仍不是 ToDesk 的同等成熟实现：

- 画面使用带接收确认的 PNG/JPEG 变化区域帧流，尚未接入硬件 H.264/AV1 编码；
- Windows 和具备 PulseAudio 工具的 Linux 支持系统声音；macOS 系统声音、多显示器选择和无人值守系统服务暂未支持；
- Windows 已使用原生桌面采集/输入并修复 DPI 缩放裁切；
- Linux/macOS 的桌面权限和输入能力受系统版本及桌面环境限制；
- 未签名的 macOS 程序首次打开时可能需要在系统安全设置中确认。

这些限制不会影响继续开发或内部远程使用，但面向大规模公网商业部署前仍需补充原生编码、签名安装包、自动化真实机矩阵和长期压力测试。
